PROBLEM STATEMENT PS05

The Flaw in Traditional Authentication

Why passwords alone fail against modern attackers, and why static 2FA drives legitimate users away.

1. Credential Stuffing & Breaches

Attackers rarely crack encryption. They take 2.4 billion credentials from public dark-web breaches and test them against corporate logins via automated botnets. A standard password form cannot distinguish between a real employee and a bot script.

PS05 VULNERABILITY

2. Rigid MFA Causes Fatigue

Forcing an SMS OTP or authenticator prompt on every single sign-in creates 40%+ friction. Users suffer "MFA Fatigue", mindlessly approving malicious prompts or abandoning transactions entirely. Security must be frictionless when safe.

USER FRICTION DILEMMA

3. Black-Box / Opaque Decisions

Most commercial adaptive systems output vague "risk detected" errors with zero explainability. SOC analysts cannot determine why a user was blocked, and developers cannot audit the weights or correlate telemetry with SQL databases.

The 5-Tier Adaptive Security Policy

DIGNITAS rejects the binary "Allow / Block" model in favor of proportional challenge escalation.

TIER 1 (0–29 PTS) ALLOW

Frictionless Passage

Known hardware ID, familiar domestic IP address, and regular login hours. User receives instant access with zero MFA fatigue.

Latency: ~4.5 ms • JWT Generated
TIER 2 (30–44 PTS) CAPTCHA

Human Verification

Repeated login attempts or mild anomaly. Enforces Cloudflare Turnstile to stop automated headless scripts without requiring email OTP.

Friction: ~2s • Headless Bot Intercepted
TIER 3 (45–59 PTS) EMAIL OTP

Step-Up MFA & Device Enrollment

Unrecognized hardware mismatch (45–59 pts). Out-of-band 6-digit passcode sent to trusted email/phone. Crucially includes: "Trust this device for 30 days?". Upon verification, device fingerprint is stored in SQLite known_devices so future sign-ins pass frictionlessly at Tier 1.

iPhone Simulator Chime / Live SMTP • Baseline Enrolled
TIER 4 (60–79 PTS) QUARANTINE

Session Quarantine & Out-of-Band Approval

Impossible velocity travel, Tor node sign-in, or high-threat anomaly (60–79 pts). Eliminates dangerous in-band password changes. Session is quarantined; an urgent Security Verification / Magic Approval Link is dispatched directly to the user's registered inbox.

Out-of-Band Email Approval • Remote Hijack Blocked
TIER 5 (80–100 PTS) BLOCK

Intrusion Lockdown & Compromised Password Advisory Email

Hit on Honeytoken decoy (backup_admin), threat watchlist IP, or 3+ repeated brute-force attacks (80–100 pts). Automated 403 Hard Block, attacking IP blacklisted in SQLite flagged_ips, and immediate Compromised Password Alert Email dispatched with one-click direct password reset link.

Blacklisted in flagged_ips SQL Table • Reset Email Sent
